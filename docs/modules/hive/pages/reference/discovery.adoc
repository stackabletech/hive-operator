= Discovery

The Stackable Operator for Apache Hive publishes a discovery https://kubernetes.io/docs/reference/generated/kubernetes-api/v1.28/#configmap-v1-core[ConfigMap], which exposes a client configuration bundle that allows access to the Apache Hive cluster.

The bundle includes an Apache Thrift connection string to access the Hive Metastore service. This string may be used by other operators or tools to configure their products with access to Hive.

== Example

Given the following Hive cluster:

[source,yaml,subs="normal,callouts"]
----
apiVersion: hive.stackable.tech/v1alpha1
kind: HiveCluster
metadata:
  name: {clusterName} # <1>
  namespace: {namespace} # <2>
spec:
  clusterConfig:
    metadataDatabase:
      postgresql:
        host: postgresql
        database: hive
        credentialsSecretName: hive-credentials
    warehouseDir: s3a://my-bucket/warehouse/
  metastore:
    roleGroups:
      default: # <3>
        replicas: 2
---
apiVersion: v1
kind: Secret
metadata:
  name: hive-credentials
type: Opaque
stringData:
  username: hive
  password: hive
----
<1> The name of the Hive cluster, which is also the name of the created discovery ConfigMap.
<2> The namespace of the discovery ConfigMap.
<3> A role group name of the metastore role.

The resulting discovery ConfigMap is `{namespace}/{clusterName}`.

== Contents

The `{namespace}/{clusterName}` discovery ConfigMap contains the following fields where `{clusterName}` represents the name and `{namespace}` the namespace of the cluster:

`HIVE`::
====
Contains the thrift protocol connection string for the Hive metastore service.
The address and port are the ones published by the `{clusterName}-metastore` xref:listener-operator:listener.adoc[Listener], so they depend on the xref:usage-guide/listenerclass.adoc[ListenerClass] in use.
For the default `cluster-internal` ListenerClass this is:

[subs="attributes"]
  thrift://{clusterName}-metastore.{namespace}.svc.cluster.local:{metastorePort}

This entry is only present if the Thrift API is enabled (`spec.clusterConfig.thriftApi.enabled`, which is the default).
====

The discovery ConfigMap does not contain an entry for the xref:usage-guide/iceberg-rest-catalog.adoc[Iceberg REST catalog] yet.

WARNING: Using the Hive metastore in high availability mode (replicas > 1) does not work with Derby but instead requires a properly configured database like PostgreSQL or MySQL.

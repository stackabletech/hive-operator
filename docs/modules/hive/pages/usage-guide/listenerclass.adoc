= Service exposition with ListenerClasses
:description: Configure the Hive service exposure with listener classes: cluster-internal, external-unstable or external-stable

The Apache Hive metastore offers a Thrift API (port `9083`) and, optionally, an xref:usage-guide/iceberg-rest-catalog.adoc[Iceberg REST catalog] (port `9001`).
The operator deploys a xref:listener-operator:listener.adoc[Listener] for the Metastore pods, which exposes the enabled APIs.

The listener defaults to only being accessible from within the Kubernetes cluster, but this can be changed by setting `.spec.metastore.roleConfig.listenerClass`:

[source,yaml]
----
spec:
  metastore:
    roleConfig:
      listenerClass: "cluster-internal" <1>
    roleGroups:
      default:
        replicas: 1
----
<1> Specify one of `external-stable`, `external-unstable`, `cluster-internal` (the default setting is `cluster-internal`).
